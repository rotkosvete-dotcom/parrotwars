PARROT WARS (Minecraft 1.16.5, Forge 36.2.34) - готовый проект под твою сборку

КАК ПОЛУЧИТЬ JAR (один раз настроить):
1. Поставь JDK 8 (Temurin 8: adoptium.net). Нужен именно JDK, а не JRE.
2. Скачай Forge MDK 1.16.5-36.2.34 (files.minecraftforge.net -> 1.16.5 -> 36.2.34 -> Mdk) и распакуй.
3. Из MDK скопируй в эту папку: папку "gradle" (с заменой), файлы gradlew и gradlew.bat.
   (build.gradle, settings.gradle, src - НЕ копируй из MDK, оставь мои.)
4. Открой cmd в этой папке, убедись что JAVA_HOME указывает на JDK 8, и запусти:
       gradlew build
   Первый раз качает много (10-20 минут).
5. Готовый файл: build\libs\parrotwars-1.16.5-1.0.0.jar
6. Положи его в папку mods твоего экземпляра:
   ...\instances\1.16.5\minecraft\mods
   Запускай игру (Forge 36.2.34, как у тебя).

БЫСТРЫЙ ТЕСТ БЕЗ СБОРКИ JAR: gradlew runClient

ИГРА:
- Креатив -> вкладка "Разное": яйцо Попугай-солдат, яйцо Голубь, Рация командира.
- Приручение: ПКМ семенами пшеницы по попугаю-солдату.
- Рация: ПКМ по блоку - идти туда; ПКМ по мобу - атаковать; ПКМ в воздух - следовать;
  Shift+ПКМ в воздух - держать позицию.

ВАРИАНТ БЕЗ УСТАНОВКИ JDK/MDK (через GitHub):
1. Создай репозиторий на github.com, загрузи в него все файлы этого проекта (вместе с папкой .github).
2. Вкладка Actions -> дождись зелёной галочки (5-10 минут).
3. Открой запуск -> внизу Artifacts -> parrotwars-jar -> скачай, внутри будет готовый .jar.
4. Положи jar в ...\instances\1.16.5\minecraft\mods
